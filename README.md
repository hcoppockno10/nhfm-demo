# NHFM Stage 1 Demo

A demonstration of how the NHS Foundation Model (NHFM) will be deployed in clinical trial **Stage 1**, focusing on medication safety monitoring.

**Note:** This demo represents the Stage 1 use case only. The NHFM programme encompasses additional stages, capabilities and work streams beyond what is shown here. For more information about the NHFM programme, please contact: **harry.coppock@dsit.gov.uk**

## Overview

This demo illustrates the end-to-end workflow for AI-assisted medication safety:

1. **Automated Patient Review** - NHFM monitors patient records to identify potential medication safety issues
2. **Patient Engagement** - Guardrailed chat interface via NHS App to gather additional information
3. **Clinician Review & Approval** - Human-in-the-loop validation of AI assessments and proposed actions
4. **Execution & Audit Trail** - Approved actions are executed with full traceability

## Key Principles

- All clinical decisions require explicit clinician approval
- No medical advice given directly to patients without oversight
- Complete audit trail for clinical governance
- AI assists but never replaces clinical judgement
